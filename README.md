# 🎮 Dashboard de Retenção & Churn - Xbox Game Pass

Este projeto consiste numa análise exploratória e na criação de um dashboard interativo focado no serviço de subscrição **Xbox Game Pass** da Microsoft, analisando métricas de retenção, comportamento dos jogadores e fatores de *churn* (cancelamento).

---

## 📊 Métricas & Insights Principais

- **Métricas Gerais:** Monitorização de Assinaturas Ativas, Taxa Geral de Churn e Média de Horas Jogadas por Mês.
- **Análise de Engajamento:** Verificação da forte correlação entre o tempo de jogo e a retenção de clientes.
- **Segmentação por Plano e Dispositivo:** Comparação do *churn* entre PC Game Pass, Console Game Pass e Ultimate em múltiplos dispositivos (Console, PC, Cloud).
- **Filtros Dinâmicos:** Interface web no Streamlit para filtragem por plano e ecossistema de jogo.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.12+
- **Análise de Dados:** Pandas, NumPy
- **Visualização de Dados:** Plotly Express
- **Dashboard Web:** Streamlit
- **Notebook Exploratório:** Jupyter Notebook (`.ipynb`)
- **Controlo de Versão:** Git & GitHub
